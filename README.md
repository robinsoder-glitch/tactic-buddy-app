# Tactics Board Pro

Jag skulle vilja bygga en app som är en taktiktavla för fotboll. Det skall gå att sätt ut spelar på en plan och sen animera löpningar och passningar. Det skall även gå att sätta in namn och bilder på spelarna i en ”bank” så man kan sätta ut olika spelare.

This project was built with [Lovable](https://lovable.dev).
